10. STANDARD SCALER
======================================================================

IMPORT:

from sklearn.preprocessing import StandardScaler

PURPOSE:

StandardScaler standardizes numerical features.

Standardization transforms a variable approximately according to:

z = (x - mean) / standard deviation

After standardization:

• Mean is approximately 0
• Standard deviation is approximately 1

PROJECT ROLE:

The clustering variables are:

• Age
• Annual Income
• Spending Score

These variables have different numerical ranges.

For example:

Age is approximately between 18 and 70.

Annual Income is approximately between 15 and 137.

Spending Score is approximately between 1 and 99.

Without scaling, variables with larger numerical ranges could have
greater influence on distance-based clustering.

The project therefore creates:

X_scaled

from:

X

using StandardScaler.

PROJECT IMPORTANCE:

Standardization ensures that the three clustering variables are
placed on a comparable scale before distance-based clustering.

Used by:

• K-Means
• Agglomerative Hierarchical Clustering
• DBSCAN

12. K-MEANS CLUSTERING
======================================================================

IMPORT:

from sklearn.cluster import KMeans

PURPOSE:

K-Means is a centroid-based unsupervised clustering algorithm.

It divides observations into K clusters.

The algorithm works by:

1. Selecting cluster centroids
2. Assigning observations to the nearest centroid
3. Updating centroid positions
4. Repeating the process until convergence

PROJECT ROLE:

K-Means is the primary clustering algorithm in the project.

Candidate values of K are evaluated.

The project investigates K values from 2 to 10.

The analysis considers:

• Elbow method
• Silhouette Score
• Cluster structure

The final reference solution uses:

K = 6

The selected K-Means model is then used to create customer
segments.

PROJECT IMPORTANCE:

K-Means provides an interpretable segmentation of customers based
on:

• Age
• Annual Income
• Spending Score

requirements.txt:

scikit-learn

14. DBSCAN
======================================================================

IMPORT:

from sklearn.cluster import DBSCAN

FULL NAME:

Density-Based Spatial Clustering of Applications with Noise

PURPOSE:

DBSCAN is a density-based clustering algorithm.

Unlike K-Means:

• It does not require a predefined number of clusters.
• It can identify dense regions.
• It can classify observations as noise.
• It can identify non-centroid-based structures.

PROJECT ROLE:

DBSCAN provides a complementary view of the customer dataset.

The project investigates:

• eps
• min_samples
• Number of clusters
• Noise observations
• Coverage
• Silhouette Score
• Davies-Bouldin Index
• Calinski-Harabasz Index

A 4-nearest-neighbour distance analysis is also used to provide
evidence for candidate eps values.

PROJECT IMPORTANCE:

DBSCAN is particularly useful for investigating whether some
customers behave differently from dense customer groups.

These observations may be identified as DBSCAN noise.

requirements.txt:

scikit-learn

16. SILHOUETTE SCORE
======================================================================

IMPORT:

from sklearn.metrics import silhouette_score

PURPOSE:

The Silhouette Score evaluates how well observations fit within
their assigned clusters compared with other clusters.

General interpretation:

Higher values generally indicate stronger cluster cohesion and
separation.

Values near zero indicate overlapping cluster boundaries.

Negative values can indicate potentially poor assignments.

PROJECT ROLE:

Silhouette Score is used for:

• K-Means model selection
• Hierarchical clustering evaluation
• DBSCAN evaluation
• Algorithm comparison

Known project results:

K-Means:

0.4284

Agglomerative:

0.4201

DBSCAN:

0.5454

IMPORTANT DBSCAN NOTE:

For DBSCAN, the metric is calculated using non-noise observations.

from sklearn.metrics import davies_bouldin_score

General interpretation:

Lower values are generally better.

PROJECT ROLE:

It is used to complement Silhouette Score during clustering
evaluation.

Known results include:

Calculated as part of final model evaluation.

The metric helps provide another perspective on cluster quality.

18. CALINSKI-HARABASZ INDEX
======================================================================

IMPORT:

from sklearn.metrics import calinski_harabasz_score

PURPOSE:

The Calinski-Harabasz Index evaluates the ratio between
between-cluster dispersion and within-cluster dispersion.

General interpretation:

Higher values generally indicate better-defined clustering
structure.

PROJECT ROLE:

It is used alongside:

• Silhouette Score
• Davies-Bouldin Index

for a more comprehensive evaluation.

Known results:

Agglomerative:

127.99

DBSCAN:

176.91

The metric contributes additional quantitative evidence when
comparing clustering solutions.

linkage() creates the hierarchical clustering linkage matrix.

The linkage matrix records how observations or clusters are
progressively merged.

PROJECT CONFIGURATION:

Method:

Ward

Distance:

Euclidean

PROJECT ROLE:

The linkage matrix is used to create the hierarchical structure
visualized through a dendrogram.

Example:

    X_scaled,
    method="ward",
    metric="euclidean"
)

The resulting structure contains information about the sequence
and distance of hierarchical merges.

======================================================================

from scipy.cluster.hierarchy import dendrogram

clustering.

• How observations/groups are merged
• The sequence of merging
• Linkage distances
• Hierarchical structure

PROJECT ROLE:

The dendrogram is used in the hierarchical clustering section.

It helps visually investigate how customer observations form
progressively larger groups.

The project also uses a reference cut corresponding approximately
to the K-Means reference cluster count.

IMPORTANT:

The dendrogram provides structural evidence.

Final model quality is evaluated using quantitative metrics rather
than relying only on visual interpretation.
