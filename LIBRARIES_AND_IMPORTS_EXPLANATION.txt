📥 Import:

from sklearn.preprocessing import StandardScaler

🎯 Purpose:
Feature Standardization

📖 Description:
StandardScaler transforms numerical features so that they have an
approximately standardized scale.

The resulting features have approximately:

📌 Mean = 0
📌 Standard Deviation = 1

🔧 Role in This Project:

The clustering features are:

👤 Age
💰 Annual Income
🛍️ Spending Score

These variables have different numerical ranges.

Scaling is important because K-Means, Hierarchical Clustering, and
DBSCAN use distance-based calculations.

💡 Example:

scaler = StandardScaler()

X_scaled = scaler.fit_transform(X)

🎯 Benefit:

No single feature dominates clustering simply because it has a
larger numerical scale.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🤖 10. K-MEANS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📥 Import:

from sklearn.cluster import KMeans

🎯 Purpose:
Centroid-Based Clustering

📖 Description:
K-Means is an unsupervised machine learning algorithm that divides
observations into a predefined number of clusters.

Each customer is assigned to the nearest cluster centroid.

🔧 Role in This Project:

K-Means is one of the three main clustering algorithms implemented.

Candidate values:

K = 2 to 10

The Elbow Method and Silhouette Score were used to evaluate the
candidate values.

🏆 Final Configuration:

🔢 Number of Clusters : 6
📉 Inertia             : 133.87
📊 Silhouette Score    : 0.4284

K-Means was then used to create six customer profiles based on:

👤 Age
💰 Annual Income
🛍️ Spending Score


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🌳 11. AGGLOMERATIVE CLUSTERING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📥 Import:

from sklearn.cluster import AgglomerativeClustering

🎯 Purpose:
Hierarchical Clustering

📖 Description:
Agglomerative Clustering follows a bottom-up hierarchical approach.

Initially, every observation is treated as an individual cluster.
Clusters are progressively merged based on similarity and distance.

🔧 Project Configuration:

🌳 Algorithm  : Agglomerative Clustering
🔗 Linkage    : Ward
📏 Metric     : Euclidean
🔢 Clusters   : 6

📊 Results:

Silhouette Score         : 0.4201
Davies-Bouldin Index     : 0.8521
Calinski-Harabasz Index  : 127.99

The resulting clusters were profiled and compared with K-Means and
DBSCAN.

🌐 12. DBSCAN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📥 Import:

from sklearn.cluster import DBSCAN

🎯 Purpose:
Density-Based Clustering

📖 Description:
DBSCAN stands for:

Density-Based Spatial Clustering of Applications with Noise

Unlike K-Means, DBSCAN does not require the number of clusters to be
specified in advance.

It identifies dense regions and can classify observations outside
those regions as noise.

🔑 Important Parameters:

📏 eps
👥 min_samples

🔧 Project Configuration:

eps         : 0.53
min_samples : 8

📊 Final Results:

Clusters          : 4
Noise Points      : 73
Coverage          : 63.5%
Silhouette Score  : 0.5454
Davies-Bouldin    : 0.6222
Calinski-Harabasz : 176.91

💡 DBSCAN was also useful for identifying observations that did not
belong to regular density-based customer groups.

1️⃣ SILHOUETTE SCORE
──────────────────────────────────────────────────────────────────────

📥 Import:

from sklearn.metrics import silhouette_score

🎯 Purpose:
Measure cluster cohesion and separation.

📖 Description:
Silhouette Score compares how similar an observation is to its own
cluster with how similar it is to other clusters.

📈 General Interpretation:

Higher Score
      ↓
Better-defined cluster separation

🔧 Project Usage:

Used for:

📊 K-Means K selection
🤖 K-Means evaluation
🌳 Hierarchical evaluation
🌐 DBSCAN evaluation
⚖️ Algorithm comparison

Measure cluster similarity.

📖 Description:
Davies-Bouldin Index evaluates cluster compactness and separation.

📉 General Interpretation:

Lower Value
      ↓
Better clustering structure

🔧 Project Usage:

Used in:

📊 Clustering evaluation
🌐 DBSCAN parameter analysis
⚖️ Algorithm comparison
